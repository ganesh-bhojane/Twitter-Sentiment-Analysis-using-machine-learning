# Overview
This project performs sentiment analysis on tweets using Natural Language Processing (NLP) and Machine Learning. The model classifies tweets into sentiment categories such as Positive, Negative, and Neutral.

# Features
Text preprocessing and cleaning
Feature extraction using TF-IDF Vectorization
Sentiment classification using Logistic Regression
Model saving and loading using Joblib
Predict sentiment for custom tweets

# Technologies Used
Python
Pandas
NumPy
Scikit-learn
NLTK
Joblib
Jupyter Notebook

# Dataset

The dataset contains tweets labeled with sentiment classes. Text data is cleaned and transformed before model training.

# Model Performance
Logistic regression = 77%
Multinomial Naive Bayes = 75%
